26R3.1 新功能

首个公开发布带来的 40 项平台能力，按产品线分类。

总览

首个公开发布，五大板块

26R3.1 是 Vivarcus 的首个公开发布。以下能力均随本版本首次交付；后续版本的新增与增强将逐版记录在本栏目。

平台核心
对象模型与元数据驱动 UI

以 MDL 声明式配置对象、字段与页面布局，业务应用无需编写代码即可搭建与演进。

生命周期与工作流

状态机、审批流与任务分配全部可配置，业务推进到哪一步由系统自动路由。

安全与权限

基于角色的访问控制与精细化权限，支持单点登录集成。

审计追踪

完整的审计日志与变更追踪，满足监管审计要求。

电子签名

受控文档电子签名，满足 21 CFR Part 11 要求。

报告与仪表板

多维数据看板与自定义报告，实时掌握试验进度、文档状态与运营指标。

任务与通知

用户任务与任务仪表板，SDK 可触发站内通知。

公开 API 与查询语言

REST API 与 VQL 查询语言，标准接口与现有系统对接。

命令行与 SDK

ov CLI 覆盖配置、数据与验收自动化；SDK 支持扩展开发。

Vault AI

AI 助手 Tab 与 Query Agent，用自然语言查询数据，支持 TOLABEL() 标签筛选。

沙盒与环境管理

沙盒环境创建、刷新与配置导入导出，发布列车（ADCV）统一管理版本。

跨组织协同

集团与事业部两级管理，申办方与 CRO 之间共享文档与协作。

eTMF 文档管理
TMF 首页与浏览器

按研究层级浏览主文件，快速定位文档与结构缺口。

文档上传与自动归档

批量上传文档并自动归档到正确分类，全程版本控制。

DIA TMF 分类与文档类型

基于 DIA TMF 参考模型的标准分类与文档类型体系。

EDL 预期文档

预期文档清单（EDL）与模板化管理，提前发现文档缺口。

里程碑

研究里程碑与预期文档联动，及时预警延迟风险。

审阅工作流

文档审阅与批准流程，支持指派审阅人并记录完整意见。

质量问题

质量问题与纠正措施追踪，闭环管理从发现到解决。

研究层级与人员

研究、国家、中心层级建模与研究人员目录管理。

CTMS 临床运营
研究生命周期

从启动到关闭的研究全生命周期管理，里程碑自动追踪。

站点生命周期

站点从可行性评估到关闭的全流程状态管理。

受试者追踪

受试者入组进度与偏离实时监控。

临床任务

临床任务分配与追踪，工作不遗漏。

监测访视

监测访视计划、执行与发现记录一体化管理。

SAE 追踪

严重不良事件记录与追踪。

问题管理

问题与 CAPA 闭环追踪，从发现到解决全程留痕。

研究指标

入组、里程碑、文档等多维指标自动汇总。

仪表板

研究组合与单研究仪表板，进度与健康状态一目了然。

全球目录

机构、中心与人员信息的全局统一目录。

Study Startup
中心可行性

可行性问卷调查与评分，科学筛选研究站点。

启动活动看板

启动活动甘特图与看板，可视化追踪每个站点的启动进度。

文档包管理

启动文档包管理与追踪，确保准备就绪。

与 eTMF / CTMS 打通

站点信息与文档数据同源，无需重复录入。

管理与运维
管理控制台

基础管理控制台，覆盖用户、角色与核心设置（部分高级页面随后续版本提供）。

用户与组

用户、组与集团-事业部组织管理。

配置打包与发布载荷

配置以声明式载荷打包、校验与部署，跨环境一致交付。

发布编排

vctl 发布命令与发布列车管理，升级可追溯、可回滚。

数据集成

直接数据 API 与第三方集成接口，预置连接器开箱即用。

多租户与数据隔离

POD 级部署隔离，各事业部数据相互独立。

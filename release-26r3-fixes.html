26R3.1 已修复问题

发布前收敛阶段修复的 20 项问题。

说明

发布前收敛

以下问题在 26R3.1 发布前已修复并随本版本交付，按领域分组。

平台与查询
会话过期恢复

登录会话过期后，界面自动清除登录态并跳回登录页，不再白屏或无限转圈。

多标签页会话

用 Ctrl+点击在新标签页打开页面不再被踢回登录页，登录态在标签页间保持。

页面无限刷新

修复研究管理、TMF 首页与工作流启动对话框的无限刷新循环，页面加载恢复正常。

Vault Owner 操作权限

Vault Owner 现在可以查看并执行对象与文档的生命周期操作，此前工具栏为空。

日期录入体验

日期字段支持直接键入或粘贴，日历弹层不再裁切、跳动或遮挡输入框。

eTMF 文档
TMF 查看器终态过滤

eTMF 文档查看器不再显示已取代、已作废、已删除等终态文档，列表符合 eTMF 规范。

Binder 归档锁定

Binder 获批后结构与版本绑定编辑被锁定，须先创建草稿才能修改，防止误改已归档内容。

Binder 详情页

补齐签名区与工作流时间线，选择父级章节时子文档一并列出，并支持对象记录与 Binder 视图切换。

CTMS 临床运营
显示名称修复

研究管理与 CRA 工作台不再把中心状态、监查类型等显示为内部 ID，正确显示选项标签与生命周期状态。

受试者详情字段

受试者详情页补上「初始知情同意日期」字段。

Finalize 权限

审查通过状态下 Owner 可以执行 Finalize，不再误报无权限。

记录页打开失败

修复 Select Site 与 Monitoring Event 记录页无法打开的问题。

工作流与生命周期
未认领任务转派

未认领的审批任务在时间线上直接显示可指派人员，便于转派处理。

审计日志文案

审计日志显示阶段标签与规范的电子签名文案。

配置包导入状态

修复入站配置包导入后列表与 Validate 状态不可见、Review & Deploy 后状态不同步的问题。

Vault AI
对话体验

文档翻译不再反复询问目标语言；多轮对话保留查询上下文；查询失败时给出易懂提示而非解析器报错。

本地化
中文术语修正

修正受试者状态 Consented 的中文误译，统一试用手册状态用词。

工作流界面翻译

补齐 PD Review 工作流启动对话框与审查任务的中文翻译。

环境与部署
沙盒创建修复

修复升级 ADCV 26.02.0 后无法创建沙盒的问题。

操作自动恢复

服务重启后自动恢复中断的沙盒创建/刷新操作，不再残留卡死状态。

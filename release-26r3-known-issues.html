26R3.1 已知问题

当前版本的已知限制与说明，均不影响核心功能使用。

26R3 发布概览 新功能 已修复问题 已知问题 关于版本发布 预发布 FAQ
说明

透明披露，持续改进

以下限制为 26R3.1 的已知情况，已列入后续版本规划。状态随版本更新。

搜索为单对象范围

首版搜索限定在单个对象内，暂不提供跨对象搜索、相关性排序与管理员可配置的默认搜索页。

本地化覆盖仍在扩展

中文界面覆盖范围持续扩展中；每种语言当前仅支持一套翻译（不支持 Label Sets），文档内容的多语言自动处理不在范围内。

Vault AI 需配置外部 LLM

平台不捆绑托管模型：启用 AI 助手与 Query Agent 前，部署方需配置 LLM 连接（默认连接或 BYO Bedrock / Azure / Google）与相应凭据。

通知发送入口有限

首版仅 SDK Action 可发送通知，Record Trigger 发送将在后续版本放开；邮件抑制名单开关页尚未提供。

管理控制台分期交付

Configuration 等高级页面将在后续版本提供，当前可通过 CLI 或 API 完成同等配置。

部分高级字段类型后续提供

汇总计算字段（Rollup）首版仅支持注册，计算能力与 raw 类型对象的高级操作将在后续版本提供。

如发现未列出的问题，欢迎通过 GitHub Issues 反馈，我们会评估并纳入后续版本。

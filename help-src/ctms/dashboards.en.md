## Two Workbenches

CTMS provides two workbenches sharing the **Study / Country / Site** three-level scope selector:

| Workbench | Entry point | Audience |
|-----------|-------------|----------|
| **Study Management Homepage** | Study Management → Study Management Homepage | Study managers (operational overview) |
| **CRA Homepage** | Site Monitoring → CRA Homepage | CRAs (monitoring workbench) |

After selecting a Study, the widget grid loads; selecting Country / Site further scopes the metrics, and clearing them returns to study level.

## Study Management Homepage

| Widget | Content |
|--------|---------|
| **Summary Metrics** | Site Status / Enrolled / Complete progress (can be 0 with no data) |
| **Monitoring Compliance** | Visits Overdue semantics and Visit Report Cycle Time (can be None Due) |
| **Monitoring Status** | Counts distributed by visit type |
| **Milestones** | Milestones generated by Plan Study / Ready to Enroll |
| **My Tasks** | Personal tasks |
| **Enrollment Status** | Enrollment status (empty state allowed) |

## CRA Homepage

| Widget | Content |
|--------|---------|
| **Details** | Study details |
| **Summary Metrics** | Summary metrics |
| **Monitoring Plan** | Scope-filtered visit plan; click a visit name to drill into the Monitoring Event detail |
| **My Tasks** | Personal tasks |
| **Enrollment Status** | Enrollment status |
| **Quality** | Quality issue / deviation counts (may reflect open deviations; empty state allowed) |

## Division of Labor with the TMF Homepage

The TMF Homepage measures **document-side** health (completeness, timeliness, document quality); the two CTMS homepages measure **process-side** operations (site status, visit compliance, enrollment progress). The three entry points coexist in one Vault, used by different roles.

> If Homepage Monitoring Status is empty: verify the correct Study is selected and the Monitoring Event's Study/Country/Site bindings are correct, then refresh.

## Required Permissions & Roles

| Type | Permission | Controls |
|------|------------|----------|
| Tab | Study Management Homepage / CRA Homepage: View | Accessing the dashboards |
| Object | Study / Study Site / Monitoring Event / Milestone / Subject / Issue: Read | Data for each widget |
| Object | Clinical User Task: Read | My Tasks widget |

Widget data is scoped by dynamic sharing: users only see data within the scope (study/country/site) granted by their Team Role.

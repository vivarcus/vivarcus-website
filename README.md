# Vivarcus Website

Source of [vivarcus.com](https://vivarcus.com/) — marketing site and help center for the Vivarcus platform (eTMF, CTMS, Study Startup for life sciences).

## Structure

| Path | Purpose |
|------|---------|
| `*.html` | Marketing pages (home, products, about, trial) and SEO guides (eTMF / CTMS / system comparison) |
| `css/`, `js/` | Styles and i18n engine (zh-CN / en-US) |
| `help/` | Generated help center pages |
| `help-src/` | Help center markdown sources + build config |
| `tools/build_help.py` | Static help center builder |

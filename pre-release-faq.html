预发布

提前验证，安心升级

预发布是新版本正式发布前的验证窗口：先在沙盒上运行新版本，确认既有配置与流程表现一致，再迎接生产升级。以下为常见问题。

什么是预发布？

预发布是新版本正式发布（GA）前的验证窗口：您可以在沙盒上先运行新版本，验证既有配置、工作流与关键流程的表现，再等待生产 Vault 统一升级。26R3.1 是 Vivarcus 的首个公开发布，后续版本的预发布时间表将在发布说明页随版本公布。

预发布什么时候开始？

见发布说明页的「发布时间表」；后续版本的预发布日期将在对应版本的发布说明中公布。

预发布沙盒里有什么？

与普通沙盒一致，按需二选一：仅配置载荷（配置与设置，不含业务数据、文档与用户），或含数据载荷（源沙盒的完整拷贝，含用户与归属）。预发布验证通常使用仅配置载荷即可。

如何创建或刷新预发布沙盒？

通过管理控制台的沙盒管理，或使用 CLI：ov vault sandbox create / ov vault sandbox refresh。两者均为异步操作，完成后会收到通知。

沙盒能提前升到新版本吗？

可以。目标版本高于源版本时，系统在复制后自动前向升级（clone + Upgrade）——这正是预发布验证所依赖的机制；目标版本低于源版本时会被拒绝，不会误降级。

是否必须参与？

否，预发布是自愿的。但我们建议在每次生产升级前，至少在沙盒上完成一轮关键流程验证。

如何了解新功能？

查看发布说明的「新功能」页，按产品线列出了每个版本交付的能力。

预发布结束后发生什么？

生产 Vault 由平台统一编排升级到新版本，现有文档与进行中的工作不受影响；客户不能自行选择跳过或延迟升级。

遇到问题怎么办？

先查看发布说明的「已知问题」页；未列出的问题欢迎通过 GitHub Issues 反馈，我们会评估并纳入后续版本。

预发布机制随发布体系持续演进，本页内容将随版本更新。

想深入了解？

查看帮助中心的操作文档，或申请试用体验 26R3.1。
